Get the periodic ping interval

Retrieves the interval of the periodic ping sweep.

basicAuth

Responses

Server

http://wol.local/settings/ping_period

Response samples

  • 200
Content type
application/json
{
  • "success": true,
  • "message": "Operation completed successfully",
  • "data": {
    • "pingPeriod": 60000
    }
}

Update the periodic ping interval

Sets the interval of the periodic ping sweep, in seconds. Only the listed values are accepted; 0 disables the sweep. The response echoes the value back in seconds.

Authorizations:
basicAuth
Request Body schema: application/json
required
pingPeriod
required
integer <int64> (PingPeriodSeconds)
Enum: 0 60 300 600 900 1800 2700 3600 10800 21600 43200 86400

Interval in seconds; 0 disables the periodic ping sweep.

Responses

Server

http://wol.local/settings/ping_period

Request samples

  • Payload
Content type
application/json
{
  • "pingPeriod": 60
}

Response samples

  • 200
  • 400
  • 405
Content type
application/json
{
  • "success": true,
  • "message": "Operation completed successfully",
  • "data": {
    • "pingPeriod": 60
    }
}
